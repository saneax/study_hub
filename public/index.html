Edge-Native Full-Stack Architecture

Cloudflare Pages + D1 SQL + R2 Storage + Workers AI

This dashboard is engineered with a dual-mode storage & AI adapter: when deployed on Cloudflare Pages, it binds directly to env.DB (D1), env.BUCKET (R2), and env.AI (Workers AI). In local/Canvas preview, it seamlessly persists to local storage while simulating edge AI pipelines.

1. Pages Functions

Single `functions/api/[[route]].js` catch-all router serving REST & AI endpoints at the edge with zero cold starts.

2. Cloudflare D1 (`env.DB`)

6 normalized SQLite tables (`courses`, `decisions`, `study_logs`, `notes`, `challenges`, `mock_exams`).

3. Cloudflare R2 (`env.BUCKET`)

Zero-egress object bucket (`study-hub-assets`) storing architecture diagrams, `kubeconfig` templates & YAML labs.

4. Workers AI (`env.AI`)

Pre-processes messy notes (`llama-3.1-8b-instruct` + `bge-base-en-v1.5`) & post-processes flashcards and readiness audits.
